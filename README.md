# Medical Shop Management System

Frontend-only demo built with React, Vite, Tailwind CSS, React Router and localStorage.

## Run

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Demo login

- Email: `admin@medicare.com`
- Password: `admin123`

## Features

- Login/logout
- Responsive dashboard
- Medicine list
- Add, edit and delete medicine
- Search and category/status filters
- Stock status
- Expiry tracking
- Supplier details
- Supplier management
- Dashboard statistics
- localStorage persistence
- Responsive desktop/tablet/mobile layout

All demo data is stored in the browser's localStorage. No backend or MongoDB is required for this demo.
